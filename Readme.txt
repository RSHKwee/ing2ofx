Introduction

The purpose of this (Java) application is to convert ING (www.ing.nl) CSV files or SNS (www.snsbank.nl) XML or ZIP files into OFX files that can be read by a program such as GnuCash (www.gnucash.org).

What's new:
- Java upgraded to version 25.
- The SNS XML file can be downloaded as a zip file; this is now supported.
- Module tests have been upgraded to JUnit 5.
- Some refactoring has been done.
- Dependencies have been updated to the most recent versions.
